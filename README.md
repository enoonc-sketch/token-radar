Token Radar ranks pre-token DeFi protocols by an implied value derived from a sealed DefiLlama snapshot (TVL, seven-day growth, age with no token, chain breadth and category share), and gives every protocol a concrete farm plan with costs and times. The board covers the snapshot's 40-protocol watchlist, adds 138 pre-token protocols below the floor, and ends with 24 live-token protocols at the model floor. The dashboard is a static page with no network: sort, filter, a per-protocol detail view and a sandbox that re-runs the model.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input token-radar-01-kit/input/snapshot.json
```
